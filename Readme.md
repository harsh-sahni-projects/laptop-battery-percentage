# About

Running this project will show laptop's current battery percentage on a floating window on bottom right of screen.

# Features / Stages

1. Text Blinking and Beep sounds on battery < 15%

2. Text color orange on battery > 15%

3. Text color Green on battery > 30%

4. Text color Blue if charger plugged in (battery charging)

# How to use

1. Install python

2. Make python env using command: `python -m venv battery_env`

3. Activate the env: `source battery_env\Scripts\activate`

4. Run the script: `python main.py`
